# 0003. Свой рендер чата на Rust

Чат запись берём собственным GQL-клиентом (запросы сверяем с TwitchDownloader, MIT), оверлей рисуем сами (cosmic-text + tiny-skia) в RGBA-кадры и отдаём ffmpeg через pipe. Один и тот же код рисует превью в GUI и финальное видео.

Альтернативы: TwitchDownloader CLI как sidecar (.NET, чужой вид), HTML в webview со снимками кадров (медленно и хрупко). Решение дорогое по объёму, но определяет внешний вид и скорость.
