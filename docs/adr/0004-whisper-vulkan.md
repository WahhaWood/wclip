# 0004. Распознавание речи на видеокарте через Vulkan

whisper.cpp собран с бэкендом Vulkan: один код для NVIDIA, AMD и Intel на Windows и Linux, загрузчик Vulkan ставится вместе с драйвером видеокарты. Замер 2026-10-21 (RX 5700 XT, минута речи): процессор 51 с, видеокарта 12.8 с. Видеокарта используется, если найдена дискретная; сбой на ней — повтор на процессоре, в настройках субтитров можно выбрать процессор.

Цена: загрузчик Vulkan (`libvulkan.so.1`, `vulkan-1.dll`) линкуется обычной зависимостью, без него программа не запускается даже для нарезки (виртуальные машины, Windows Server). README это оговаривает. Сборке нужны заголовки Vulkan и `glslc` (Vulkan SDK).

Альтернативы: CUDA (сотни МБ библиотек, только NVIDIA), HIP (на Windows почти нет), отдельные DLL бэкендов `GGML_BACKEND_DL` (ломает ADR 0001), отложенная загрузка `vulkan-1.dll` (хрупко, исключения delay-load ggml не ловит).
