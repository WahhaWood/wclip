# 0004. Распознавание речи на видеокарте через Vulkan

whisper.cpp собран с бэкендом Vulkan: один код для NVIDIA, AMD и Intel на Windows и Linux, загрузчик Vulkan ставится вместе с драйвером видеокарты. Замер 2026-10-21 (RX 5700 XT, минута речи): процессор 51 с, видеокарта 12.8 с. Видеокарта используется, если найдена дискретная; сбой на ней — повтор на процессоре, в настройках субтитров можно выбрать процессор.

Изменено 2026-10-24 (решение пользователя): `vulkan-1.dll` не обязателен. На Windows он подключён отложенно (`/DELAYLOAD` в `build.rs`), а `src/vulkan_loader.rs` (`__pfnDliFailureHook2`) при отсутствии DLL подставляет `vkGetInstanceProcAddr`, у которого любая функция возвращает `VK_ERROR_INITIALIZATION_FAILED`; ggml ловит это в `ggml_backend_vk_reg` и работает без Vulkan, whisper идёт на процессоре. Раньше здесь стояло «отложенная загрузка хрупка, исключения delay-load ggml не ловит»: теперь исключения нет, потому что первый вызов в загрузчик (`vk::enumerateInstanceVersion`) получает код ошибки. Проверено на Linux (тесты); Windows без DLL проверит CI/ручной запуск. Есть Vulkan и дискретная видеокарта — whisper идёт на ней, как раньше.

Прежняя цена (до этого изменения): загрузчик линковался обычной зависимостью, без него программа не запускалась даже для нарезки (виртуальные машины, Windows Server). Сборке по-прежнему нужны заголовки Vulkan и `glslc` (Vulkan SDK). Сборке нужны заголовки Vulkan и `glslc` (Vulkan SDK).

Альтернативы: CUDA (сотни МБ библиотек, только NVIDIA), HIP (на Windows почти нет), отдельные DLL бэкендов `GGML_BACKEND_DL` (ломает ADR 0001), отложенная загрузка `vulkan-1.dll` (хрупко, исключения delay-load ggml не ловит).
