# 0002. Инструменты докачиваются при первом запуске

ffmpeg и yt-dlp не вшиты в бинарник: при первом запуске скачиваются в каталог данных приложения. yt-dlp обновляется сам (Twitch меняет внутренности часто, а yt-dlp чинится за дни).

Почему: бинарник остаётся мелким, нет проблем с лицензиями при раздаче (ffmpeg GPL-сборка не лежит в репозитории), ломающийся загрузчик чинится без нового релиза. Минус: первый запуск требует интернета.
