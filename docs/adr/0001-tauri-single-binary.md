# 0001. Tauri, один бинарник

Приложение на Tauri (Rust + веб-интерфейс), Windows и Linux. Пользователь скачивает один файл (portable `.exe`, на Linux AppImage), установка не нужна.

Почему: Electron тяжёлый (~150 МБ и отдельный Chromium), пользователь его не хочет. Rust нужен всё равно для рендера чата. Минус: на Windows нужен WebView2 (есть в Win10/11).
