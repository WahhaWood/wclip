# WClip glossary

- **VOD** — запись стрима Twitch, которую стример указывает ссылкой.
- **Файл с диска** — видео, которого нет на Twitch (запись OBS, повтор); нарезается вместо VOD, чат к нему берётся из лога чата.
- **Лог чата** — файл с сообщениями чата: журнал Chatterino (`.log`, время по часам) или JSON TwitchDownloader (время от начала VOD). Синхронизируется с файлом через «начало видео в чате».
- **Интервал** — отрезок VOD (начало–конец), который нужно вырезать.
- **Клип** — готовый видеофайл, получившийся из одного интервала. Не путать с «клипом Twitch» (clip на платформе): в WClip этого понятия нет.
- **Задание** — один запуск: одна VOD и список интервалов; даёт столько клипов, сколько интервалов.
- **Чат записи** — сообщения чата, привязанные ко времени VOD.
- **Оверлей чата** — картинка чата с прозрачным фоном, накладываемая на видеоряд клипа.
- **Пресет оверлея** — сохранённые настройки оверлея: угол, размер, шрифт, прозрачность, ширина, время жизни сообщения.
- **Смайлы** — эмодзи Twitch и сторонние (7TV, BTTV, FFZ).
- **Инструменты** — внешние программы (ffmpeg, yt-dlp), которые WClip докачивает при первом запуске.
